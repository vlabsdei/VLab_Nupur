### About the Experiment

This virtual lab simulates Electrical Die Sorting (EDS), an essential quality-control stage where completed semiconductor wafers undergo automated micro-probing before packaging. Students load a multi-die wafer onto a thermal chuck, interface it with a probe card, and calibrate Supply Voltage and Test Frequency parameters to execute logic verification sweeps. By monitoring the real-time pass/fail grid map, students analyze structural timing lags and parametric gate breakdowns caused by out-of-tolerance operating parameters. Ultimately, the simulation demonstrates how proper electrical stress calibration directly optimizes manufacturing lot yields and drives speed-binning tier economics in semiconductor production.
